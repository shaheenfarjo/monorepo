تحتاج إلى [Bun](https://bun.sh)، وإلى
[Docker](https://docs.docker.com/get-docker/) لتشغيل قاعدة البيانات محلياً.

## ١. أنشئ المشروع

```sh
bun create theideaiq/a-saas my-product
cd my-product
```

ينسخ هذا الأمر القالب ويثبّت الحزم ويبدأ سجلّ Git جديداً.

## ٢. اجعله مشروعك

```sh
bun run init
```

يسألك المولّد عن اسم المؤسسة والمشروع والبلد واللغة الافتراضية والترخيص
والوحدات الاختيارية، ثم يعدّل الشيفرة وينشئ ملفات `.env.local`.

## ٣. شغّله

```sh
bun run db:start    # Supabase محلياً عبر Docker
bun run dev         # التطبيق :3000 · الموقع :3001 · الواجهة البرمجية :3002
```

ضع الرابط والمفاتيح التي يطبعها `db:start` في ملفات `.env.local`، ثم افتح
`http://localhost:3000` وسجّل الدخول بالرقم `+964 770 000 0000` والرمز
`123456`.

باقي الدليل متوفر بالإنجليزية حالياً، ونرحّب بالمساهمة في ترجمته.
